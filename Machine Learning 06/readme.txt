Predicting Pulsar Star

Pulsars are a rare type of Neutron star that produce radio emission detectable here on Earth. They are of considerable scientific interest 
as probes of space-time, the inter-stellar medium, and states of matter. Machine learning tools are now being used to automatically label pulsar 
candidates to facilitate rapid analysis. Classification systems in particular are being widely adopted,which treat the candidate data sets as 
binary classification problems.

candidate : a signal that might be a pulsar, but is not confirmed yet,
In astronomy, telescopes detect huge numbers of radio signals.

Most are:

noise
interference
satellites
random patterns

A small number could be real pulsars. So astronomers first collect possible pulsars called pulsar candidates. Then with the help of ML classify 
them into:

real pulsar
not pulsar


Signals with certain skewness, kurtosis, and SNR behavior are more likely to be real pulsars

Using Support Vector Machine classification, we successfully trained a model to distinguish pulsar star signals from non-pulsar signals 
based on statistical radio signal features. The model learned hidden patterns in astronomical data and demonstrated how machine learning 
can assist in automated astrophysical object detection.
